# 📊 Auto-EDA Data Analyzer
A lightweight, general-purpose Exploratory Data Analysis (EDA) web app built with Python, Streamlit, and Pandas.

### Features
- Dynamic file uploader (supports CSV and Excel).
- Automated categorical and numerical sidebar filtering.
- Switch between sliders and manual number inputs for precise control.
- Interactive charts (Line, Bar, Scatter) with automatic data aggregation.

### Tech Stack
- **Frontend/UI:** Streamlit
- **Data Processing:** Pandas
